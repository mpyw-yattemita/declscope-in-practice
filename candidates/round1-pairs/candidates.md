## How this was screened

1. Cloned 53 repositories (full clones under the scratchpad), ran `declscope survey -format=json ./...` (40 succeeded, raw output in `survey/`).
2. For each package with 8+ non-test files and 3+ namespaces, walked `git log --first-parent` of the package's own `.go` files since 2025-01-01 and took each pair of consecutive commits. Consecutive means no other commit touched the package's files in between (the follow-up's seed is PR1's merge commit).
3. Kept PR1 when it changed 2+ non-test files and about 40-600 non-test lines in the package and changed a test file there; titles that read as fix/refactor/chore/perf/bump were dropped. 36 repositories produced 1614 such pairs.
4. Short list: PR2 has tests, 15+ non-test lines, and is not lint/bump/docs (223 pairs, mostly merged 2026-07 or later).
5. Automated name check: parsed declarations at base and merge, then matched identifiers on the added lines of the package's test files against names new in PR1 (and PR2). This is token matching and over-reports (e.g. a local `ok` or `status` matches a new field); unexported hits for the kept pairs were checked against the test diff by hand; exported hits were taken from the tool output without a line-by-line read.
6. About 40 pairs read by hand (PR body, file list, test diff); 19 kept. 38 seed commits were tested offline as described at the top.
