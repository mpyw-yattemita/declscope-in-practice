0. pkg/server.go:218: WithUnifiedPagination is not used by any tool. It also declares a "page" parameter that ToGraphQLParams ignores ("Page is not converted to a cursor"), so a tool that used it would accept a page number and then drop it without telling the caller. Fix: Delete WithUnifiedPagination. GraphQL tools should use WithCursorPagination.
1. pkg/server.go:271: PaginationParams.ToGraphQLParams and the new PaginationParams.After field are only used by server_test.go. REST tools never declare an "after" parameter, and GraphQL tools use CursorPaginationParams. This leaves two ways to build GraphQL pagination, and one of them silently drops Page. Fix: Remove the After field and PaginationParams.ToGraphQLParams. Stop reading "after" in OptionalPaginationParams. Remove the PaginationParams subtest in TestToGraphQLParams and the "after parameter" cases in TestOptionalPaginationParams.
2. pkg/server.go:254: OptionalPaginationParams hardcodes a default perPage of 30, while the new DefaultGraphQLPageSize constant (also 30) is used for cursor pagination. The REST default is a magic number. Fix: Add a `defaultPerPage = 30` constant next to maxPerPage. Use it in OptionalPaginationParams, ListSubIssues and ListCommits (repositories.go:142).
3. pkg/discussions.go:16: pageInfoFragment, toMap and paginationVars are general GraphQL pagination helpers that take *GraphQLPaginationParams. They are defined in discussions.go, but the type they work on lives in server.go. Fix: Move pageInfoFragment, its toMap method and paginationVars to server.go, next to GraphQLPaginationParams. Consider making paginationVars a method: `func (p *GraphQLPaginationParams) Vars() map[string]any`.
4. pkg/discussions.go:272: GetDiscussion, GetDiscussionComments (line 339) and ListDiscussionCategories (line 422) decode arguments with mapstructure.Decode. Fix: Replace mapstructure.Decode with RequiredParam[string] for owner and repo, and RequiredInt for discussionNumber, as ListDiscussions does. Then drop the mapstructure import if nothing else uses it.
5. pkg/discussions.go:133: The discussion tools hardcode the strings "Repository owner" and "Repository name" (also at lines 254, 327 and 409), while the package now has DescriptionRepositoryOwner and DescriptionRepositoryName in actions.go. Fix: Replace the two mcp.WithNumber options with WithPagination(), and read the values with OptionalPaginationParams(request). Update the test to use "perPage" and regenerate the toolsnap.
